## Safety features

Trusted guardians, reviewed check-in drafts with optional actual excerpts, in-call safety guidance, manual post-call blocks/reports, an offline retry queue, and authenticated safety-service endpoints are implemented locally. Reports require administrator review before creating shared blocks. Model scores never block a number or send a message automatically.

The high-risk departure reminder appears once when returning to the app. iOS does not allow this app to intercept the Home gesture. Guardian sending remains an explicit user action in Messages or sharing; automatic push alerts and generated AI summaries are not implemented. Blocking covers callma.-handled calls rather than installing system-wide Phone blocking.

Backend verification: 9 safety-service tests, 24 ringing tests and 7 integration tests passed. HTTPS per-user provisioning, production account enrollment, physical call routing and actual message delivery remain outside this verification. See [service evidence and configuration](features-2026-10-20/backend.md).

## Transcript detector

The local Jev detector received three fine-tuning stages, source and leakage audits, short-input abstention, bounded context windows, checksummed model bundles and runtime parity verification. The V5 development candidate improved selected recorded transcripts from 19/31 to 31/31 correct. It scored 39/40 benign banking roleplays, 22/25 difficult authored contrasts, and 6/6 public audio clips passed through the app's Vosk recognizer.

These repeatedly inspected, small development collections do **not** establish 99–100% real-world accuracy. The three scam audio clips are FTC YouTube robocalls; the benign audio is human banking roleplay. Natural benign conversation evidence is transcript-only. Some scripts, actors and scenarios may overlap training sources. False alerts remain on hard benign examples. Scores are experimental indicators rather than calibrated fraud probabilities.

Five model-service tests, eleven transcript-pipeline tests and one Node connector test passed; actual V5 ONNX inference also matched reference outputs on 23 inputs per context mode and passed HTTP success/abstention checks. These verify runtime mechanics separately from detection quality.

V5 weights and source recordings remain in ignored local research folders. The deployed model and iOS on-device model bundle remain unchanged. Explicit local V5 launch instructions, metrics, source links and unresolved validation needs are in [the detector report](testing/2026-10-20-transcript/REPORT.md).
